# Project Infrastructure & Requirements

## Core Tech Stack
- **JUnit 5:** Latest version.
- **REST Assured:** API testing.
- **Playwright for Java:** UI testing.
- **AssertJ:** Fluent assertions.
- **Jackson:** JSON handling.
- **Bonus:**
    - Allure (Reporting)
    - Lombok (Boilerplate reduction)

## Deliverables
1. **GitHub Repository:**
    - Working test suite (API and UI).
    - Clear package structure.
    - `.gitignore` and `pom.xml`.
2. **README.md:**
    - Prerequisites (Java 11+, Maven 3.6+, Chrome).
    - Run instructions (All, API only, UI only).
    - Test Strategy.
    - Challenges & Solutions.
    - Future improvements.
3. **Test Report:**
    - Screenshot, Surefire HTML, or Allure report.
4. **Bonus:** CI/CD via GitHub Actions.

## Evaluation Criteria
- **Test Design (30%):** Scenarios, mix of +/- tests, structure.
- **Code Quality (30%):** Clean code, POM, DRY, assertions.
- **Architecture (25%):** Structure, reusable components, config management.
- **Documentation (15%):** README, comments, commits.
